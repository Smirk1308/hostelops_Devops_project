# ml/ — Synthetic Data and ML Models for HostelOps

## What is the data?

`ml/data/complaints.csv` is **synthetic sample data** created for the demo.
It is NOT real hostel complaint data. It was generated by `ml/generate_data.py`
using hand-written sentence templates with random place and time fillers.

## How to regenerate the data

```bash
python -m ml.generate_data
```

This writes `ml/data/complaints.csv` (deterministic; `random.seed(42)`).

## How to train the models

```bash
python -m ml.train
```

This reads the CSV and saves a trained model to `ml/model.joblib`.
`ml/model.joblib` is gitignored and must be (re)generated locally.

## What the two models predict

| Pipeline | Input | Output |
|---|---|---|
| **category** | Complaint text (TF-IDF + LogisticRegression) | One of 7 categories: Water, Electricity, Wi-Fi, Mess, Cleanliness, Furniture, Other |
| **priority** | Complaint text (TF-IDF + LogisticRegression) | One of 3 priorities: Low, Medium, High |

Both pipelines use `TfidfVectorizer(ngram_range=(1, 2))` + `LogisticRegression(max_iter=1000)`.
